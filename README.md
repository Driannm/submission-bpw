# 🌐 Project Submission: Learn Basic Web Programming - Dicoding

This project is the final submission for the Learn Basic Web Programming class from [Dicoding.com](https://www.dicoding.com/).
This class comprehensively discusses the basics of website creation using HTML and CSS as the main foundations of modern web development.
The material is structured by Dicoding's expert team so that participants can understand the concepts from the basics to their practical application in building a web page.

---

## 📚 Concepts Applied

In this project, I applied various concepts learned, such as:

- 🧱 HTML Semantic Structure

Using the `<header>`, `<main>`, `<footer>`, `<article>`, and `<aside>` elements.

- 🎨 CSS Application

To enhance the page's appearance and clarify content hierarchy.

- 🧩 **Layouting with Flexbox**
To make the website responsive on various devices (desktop, tablet, mobile).

- ⚡ **Interactivity with Simple JavaScript**
To manipulate DOM elements and make the website more vibrant.

---

## 🖥️ About the Project

This website is built with a free theme according to the submission requirements.
All resources use **relative paths** to ensure proper access across various operating systems.
The interface is designed to be **clean, responsive, and comfortable to access** on various screen sizes.
